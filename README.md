# Мой день — расписание

Личное веб-приложение: показывает текущий этап дня, прогресс, предыдущий и следующий этапы,
и подсвечивает ближайший приём препаратов. Работает по реальным часам. Открывается с телефона.

Три сценария (переключаются в приложении):
- **Пн · Ср · Пт** — «Огонь» днём, 1 час
- **Вт·Чт·Сб·Вс** — «Огонь» утром 30 мин + кардио
- **Вт·Чт·Сб·Вс** — «Огонь» утром 1 час + кардио

## Как выложить на GitHub Pages (бесплатно)

1. Зайди на github.com, создай новый репозиторий (New repository), например `moy-den`. Сделай его **Public**.
2. Кнопка **Add file → Upload files**. Перетащи ВСЕ файлы из этой папки:
   `index.html`, `manifest.webmanifest`, `icon-180.png`, `icon-192.png`, `icon-512.png`, `README.md`.
   Нажми **Commit changes**.
3. Открой **Settings → Pages**. В разделе *Build and deployment*: Source = **Deploy from a branch**,
   Branch = **main**, папка = **/ (root)**. Нажми **Save**.
4. Через 1–2 минуты вверху появится адрес вида `https://ТВОЙ-ЛОГИН.github.io/moy-den/`.

## Как пользоваться на iPhone

1. Открой этот адрес в **Safari**.
2. Нажми «Поделиться» → **«На экран „Домой“»**. Появится иконка-приложение на весь экран.
3. Утром открой приложение и выбери сценарий на сегодня. Оно пойдёт по реальным часам до 23:00.
4. Заходи когда нужно — увидишь текущий этап, сколько осталось, что дальше, и ближайший приём.
   Кнопка **«Принял»** отмечает лекарство выпитым (галочка в списке дня).
5. Кнопки **«Стоп»** и **«Сменить сценарий»** — в любой момент. На следующий день запусти заново.

## Важно про уведомления

Приложение **не шлёт системные напоминания** (звук/баннер, когда оно закрыто). Статический сайт
на iPhone этого не умеет — для фоновых пуш-уведомлений нужен отдельный сервер. Приложение показывает
актуальный этап и подсвечивает приём, когда ты его открываешь.

Если однажды захочешь именно фоновые звуковые напоминания — это делается небольшим сервисом
(веб-пуш), уже не статикой. Можно вернуться к этому отдельно.

## Правки

Всё расписание зашито в `index.html` (массив `SCEN` в начале скрипта): время этапов (`blocks`)
и приёмы (`meds`). Меняешь время/подписи там же — и заново загружаешь файл на GitHub.
