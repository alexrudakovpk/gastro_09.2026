# Мой день — расписание

Личное веб-приложение: показывает текущий этап дня, прогресс, предыдущий и следующий этапы
и подсвечивает ближайший приём препаратов. Работает по реальным часам. Открывается с телефона.

Четыре сценария (выбираются на стартовом экране):
- 🧘 **Пн · Ср · Пт** — йога длинная
- 🕡 **Вт · Чт · Сб** — «Огонь» утром 30 мин + кардио
- 🕧 **Вт · Чт · Сб** — «Огонь» утром 1 час (без БМ) + кардио
- 💤 **Вс** — без йоги, позднее пробуждение (с 07:45)

## Как выложить на GitHub Pages (бесплатно)

1. github.com → **New repository** (например `moy-den`), сделай **Public**.
2. **Add file → Upload files** — перетащи ВСЕ файлы из этой папки:
   `index.html`, `version.json`, `manifest.webmanifest`, `icon-180.png`, `icon-192.png`, `icon-512.png`, `README.md`.
   → **Commit changes**.
3. **Settings → Pages**: Source = **Deploy from a branch**, Branch = **main**, папка = **/ (root)** → **Save**.
4. Через 1–2 минуты вверху появится адрес вида `https://ТВОЙ-ЛОГИН.github.io/moy-den/`.

## Как пользоваться на iPhone

1. Открой адрес в **Safari** → «Поделиться» → **«На экран „Домой“»**. Появится иконка на весь экран.
2. Утром открой приложение, выбери сценарий. Оно идёт по реальным часам до 23:00.
3. Заходи когда нужно — видишь текущий этап, сколько осталось, что дальше и ближайший приём.
   Кнопка **«Принял»** отмечает лекарство (галочка в списке дня).
4. **«Стоп»** и **«Сменить сценарий»** — в любой момент. На следующий день запусти заново.

## Автоматическое обновление (без пересоздания ярлыка)

Приложение само проверяет файл `version.json` при каждом запуске. Ярлык на экране «Домой»
пересоздавать НЕ нужно — обновления подтягиваются автоматически.

**Чтобы опубликовать обновление:** загрузи изменённые файлы на GitHub и **увеличь число `v`
в `version.json` на 1** (было `2` → стало `3`). При следующем открытии приложение увидит новую
версию и само перезагрузится на свежую. (Самый первый переход на эту версию может потребовать
одного обычного открытия — дальше всё автоматически.)

## Про уведомления

Системных фоновых уведомлений (звук/баннер при закрытом приложении) нет — статический сайт
на iPhone этого не умеет. Приложение показывает актуальный этап и подсвечивает приём, когда открыто.

## Напоминание о курсе

С 24.10.2026 при запуске любого сценария всплывёт напоминание: месяц Альфазокса и Нексиума ×2
истёк — пора оценить курс и перевести Нексиум на ×1/день. Скрывается кнопкой «Больше не показывать».

## Правки расписания

Всё зашито в `index.html` (массив `SCEN`): этапы (`blocks`) и приёмы (`meds`). Меняешь там же,
загружаешь файл на GitHub и не забудь поднять `v` в `version.json`.
